# Store Listing Copy

## English

DeCode is a private developer tool for decoding or encoding text directly on the
page. Select text to open a lightweight panel, inspect the result, chain
operations, or download binary output. Processing happens locally in the
browser.

## Chinese (China)

DeCode 是一款面向开发者的本地文本工具，可直接在网页中处理选中的文字。
选中文本即可打开轻量面板，查看结果、连续处理或下载二进制输出。所有处理
均在浏览器本地完成。
